# Bike Sales Business Intelligence Dashboard

## Project Overview

A **Power BI Business Intelligence project** developed for a client to transform bike sales data into an interactive, decision-focused dashboard.

The project demonstrates an end-to-end analytics workflow, from **data preparation and modeling to DAX calculations, visualization, and business insights**.

> **Client Confidentiality:** The dataset has been modified/anonymized for portfolio purposes. The dashboard structure, analytical approach, KPIs, and insights remain representative of the original client use case.

---

## Objectives

* Analyze overall sales performance
* Track key business KPIs
* Identify product and category performance
* Understand customer demographics and purchasing behavior
* Analyze geographic sales performance
* Evaluate year-over-year performance
* Provide actionable business insights through interactive reporting

## Project Workflow

## Raw Data → Data Cleaning → Data Modeling → DAX Measures → Analysis → Dashboard → Business Insights

### 1. Data Preparation

* Cleaned and validated the source dataset
* Reviewed data types and data quality
* Standardized relevant fields
* Validated customer, product, geographic, and sales data

### 2. Data Modeling

* Created a structured Power BI data model
* Built a dedicated Date Table
* Established relationships between tables
* Prepared the model for time-intelligence analysis

### 3. DAX & KPIs

Developed business measures including:

* Total Revenue
* Total Profit
* Total Cost
* Total Quantity
* Previous Period Revenue
* Previous Period Profit
* Revenue Growth %
* Profit Growth %
* Revenue Contribution %

### 4. Dashboard & Analysis

The dashboard provides interactive analysis across:

* Sales Performance
* Product & Category Performance
* Customer Demographics
* Geographic Performance
* Time-Based Trends
* Revenue & Profitability

## Data Confidentiality

Because this project is based on a client use case, the original business data cannot be publicly shared.

The dataset included in this portfolio project has been **modified/anonymized to protect confidential information**. Therefore, numerical values should not be interpreted as the client's actual business figures.

The **analytical methodology, dashboard structure, KPI logic, and reporting approach** represent the work performed for the client use case.
